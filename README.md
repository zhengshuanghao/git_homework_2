# 水印应用程序 - Watermark Tool

一个功能完整的桌面水印应用程序，支持Windows和MacOS，可以为图片添加文本水印或图片水印。

## 功能特性

### 1. 文件处理
- **导入图片**: 支持单张图片拖拽或通过文件选择器导入
- **批量导入**: 可一次性选择多张图片或直接导入整个文件夹
- **支持格式**: 
  - 输入格式：JPEG, PNG, BMP, TIFF（PNG格式支持透明通道）
  - 输出格式：JPEG, PNG
- **文件列表**: 在界面上显示已导入图片的列表（缩略图和文件名）

### 2. 水印类型

#### 2.1 文本水印
- **内容**: 用户可自定义输入任意文本
- **字体**: 可选择系统字体、字号、粗体、斜体
- **颜色**: 提供调色板选择字体颜色
- **透明度**: 可调节文本的透明度（0-100%）
- **样式**: 可添加阴影或描边效果

#### 2.2 图片水印
- **图片选择**: 可从本地选择一张图片（如Logo）作为水印
- **透明支持**: 支持带透明通道的PNG图片
- **缩放**: 可按比例调整图片水印的大小
- **透明度**: 可调节图片水印的整体透明度（0-100%）

### 3. 水印布局与样式
- **实时预览**: 所有对水印的调整都在主预览窗口中实时显示效果
- **位置设置**: 
  - 预设位置：九宫格布局（四角、正中心）
  - 手动拖拽：可在预览图上通过鼠标拖拽水印到任意位置
- **旋转**: 可以任意角度旋转水印

### 4. 导出功能
- **输出目录**: 用户可指定输出文件夹，默认禁止导出到原文件夹防止覆盖
- **命名规则**: 
  - 保留原文件名
  - 添加自定义前缀
  - 添加自定义后缀
- **质量设置**: 对于JPEG格式，提供图片质量调节（0-100）
- **尺寸调整**: 导出时可调整图片尺寸（按宽度、高度或百分比缩放）

### 5. 配置管理
- **水印模板**: 
  - 保存当前水印设置为模板
  - 加载、管理和删除已保存的模板
  - 程序启动时自动加载上一次的设置

## 安装和运行

### 环境要求
- Python 3.7+
- tkinter（通常随Python安装）
- Pillow库

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行应用程序
```bash
python main.py
```

## 使用说明

### 1. 导入图片
- 点击"导入图片"按钮选择单个图片文件
- 点击"批量导入"按钮选择多个图片文件
- 点击"导入文件夹"按钮导入整个文件夹中的图片

### 2. 设置水印
- **文本水印**: 在"文本水印"标签页中设置文字内容、字体、颜色等
- **图片水印**: 在"图片水印"标签页中选择水印图片并调整大小和透明度
- **位置设置**: 在"位置设置"标签页中选择预设位置或自定义位置

### 3. 预览效果
- 在中央预览区域可以实时查看水印效果
- 可以点击文件列表切换预览不同的图片
- 可以在预览图上直接点击设置水印位置

### 4. 导出图片
- 在"导出设置"标签页中选择输出目录和格式
- 设置文件命名规则
- 点击"开始导出"按钮导出所有图片

### 5. 模板管理
- 在"模板管理"标签页中可以保存当前设置为模板
- 可以加载之前保存的模板
- 可以删除不需要的模板

## 技术实现

### 核心技术
- **GUI框架**: tkinter
- **图像处理**: Pillow (PIL)
- **配置管理**: configparser + JSON
- **跨平台**: 支持Windows和MacOS

### 主要模块
- **ImageProcessor**: 处理图像加载、缩放、格式转换
- **WatermarkManager**: 管理文本和图片水印的创建和应用
- **FileManager**: 处理文件导入、导出、批量操作
- **TemplateManager**: 管理水印配置模板的保存和加载

## 注意事项

1. **文件格式**: 确保输入的图片文件格式被支持
2. **输出目录**: 建议选择与原图片不同的输出目录
3. **内存占用**: 处理大量高分辨率图片时可能占用较多内存
4. **字体支持**: 系统中安装的字体才能在应用中使用

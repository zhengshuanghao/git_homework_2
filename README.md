# 水印应用程序 - WatermarkApp

## 📝 项目简介

这是一个功能完整的图片水印应用程序，支持文本水印和图片水印，具备现代化的拖拽界面和丰富的自定义选项。

## ⭐ 主要特性

### 🖼️ 水印功能
- **文本水印**：自定义字体、颜色、大小、透明度、旋转角度
- **图片水印**：支持PNG/JPG水印图片，可调节透明度和缩放
- **高级效果**：文本阴影、描边效果
- **位置控制**：九宫格预设位置 + 自定义坐标

### 🖱️ 拖拽导入
- **直观操作**：直接拖拽图片到预览区域
- **批量导入**：支持同时拖拽多张图片，一次性导入多个文件
- **格式支持**：JPG, PNG, BMP, GIF, TIFF, WebP
- **视觉反馈**：拖拽进入时背景变蓝色，松开鼠标完成导入
- **智能过滤**：自动识别图片文件，跳过无效格式
- **错误处理**：对无效文件显示友好提示，有效文件正常导入

### 📁 文件管理
- **多种导入方式**：按钮导入、拖拽导入、剪贴板导入
- **智能命名**：支持前缀、后缀、保留原名等命名规则
- **格式转换**：输出JPEG或PNG格式
- **尺寸调整**：支持按比例、宽度、高度或自定义尺寸调整

### 🎨 模板系统
- **模板保存**：保存常用的水印设置为模板
- **快速应用**：一键加载已保存的模板
- **设置记忆**：自动记住上次的设置

## 🚀 快速开始

### 运行应用程序
双击运行：`release/WatermarkApp_完整版.exe`

### 基本使用流程
1. **导入图片**：拖拽图片到预览区域或使用导入按钮
2. **设置水印**：在右侧面板配置文本或图片水印
3. **实时预览**：在中央区域查看水印效果
4. **批量导出**：设置输出目录，点击"开始导出"

## 🔧 开发环境

### 系统要求
- **操作系统**：Windows 7+ (推荐 Windows 10/11)
- **Python版本**：Python 3.8+ (仅开发需要，exe版本无需Python)
- **内存要求**：2GB+ RAM (处理大图片时)
- **磁盘空间**：1GB+ 可用空间

### 依赖库
- **Pillow >= 10.0.0** (图片处理)
- **pyinstaller >= 5.0.0** (打包)
- **tkinterdnd2 >= 0.3.0** (拖拽支持)
- **windnd >= 1.0.1** (Windows拖拽增强)

### 开发运行
```bash
# 安装依赖
pip install -r requirements.txt

# 运行源码版本
python main.py

# 测试拖拽功能
python test_drag_drop.py
```

### 构建exe
```bash
# 自动构建（推荐）
.\build_with_drag.bat

# 手动构建
pyinstaller --clean WatermarkApp_Drag.spec
```

## 💡 使用技巧

### 拖拽导入技巧
- **单张预览**：拖拽单张图片可以最快看到效果
- **批量处理**：拖拽多张图片进行批量水印制作
- **混合导入**：可以同时使用按钮导入和拖拽导入
- **有效区域**：整个预览区域都是有效的拖拽目标

### 文本水印最佳实践
- **英文水印**：Times New Roman + 32号 + 纯英文文本
- **中文水印**：微软雅黑 + 24号以上字体
- **复杂背景**：启用描边或阴影增强可读性
- **透明度控制**：通常50-80%效果最佳

### 图片水印建议
- **推荐格式**：PNG透明背景水印图片
- **图片尺寸**：建议200x200像素左右
- **缩放比例**：10-50%通常效果较好
- **位置选择**：角落位置不易影响主体

### 批量处理优化
- **统一设置**：先用单张图片调试好参数
- **保存模板**：将常用设置保存为模板
- **分类处理**：相似图片分组批量处理
- **备份原文件**：处理前备份重要图片

## 🔧 故障排除

### 常见问题

**拖拽功能不工作**
- 确认拖拽到预览区域（中央白色区域）
- 确认文件是支持的图片格式
- 尝试重新启动应用程序
- 如果拖拽功能不可用，程序会自动切换到按钮导入模式

**斜体效果不明显**
- 使用Times New Roman字体
- 输入纯英文文本
- 设置28号或更大字体
- 避免中文字符（会自动切换字体）

**程序启动慢或卡顿**
- 首次运行需要初始化，属正常现象
- 处理大图片时会占用更多内存
- 确保有足够的磁盘空间

**图片方向错误**
- 勾选"自动修正图片方向"选项
- 使用"强制旋转"手动调整方向
- 检查图片EXIF信息是否正确

**构建exe失败**
- 以管理员身份运行构建脚本
- 暂时关闭杀毒软件
- 确保网络连接正常，能够下载依赖包
- 检查磁盘空间是否充足（需要至少1GB）
